# Логово дракона — сервер игры по сети (версия 2)

Вторая версия сервера для игры 0.7 и новее: **список открытых комнат** и «быстрая игра».
Она работает отдельно от первого сервера (`dragla`), чтобы игроки на версии 0.6 продолжали играть на старом.
Старый сервер не трогай, пока большинство игроков не обновится.

Маленький сервер на Node.js: комнаты с кодом из 4 цифр, лобби, готовность, старт партии
и рассылка ходов всем игрокам в одном порядке. Саму игру считает каждый телефон —
сервер только раздаёт общее «зерно» случайности и действия игроков, поэтому нагрузка минимальная.

Игра ждёт сервер по адресу **`wss://dragla2.relaxdev.ru`** (проект `dragla2` на RelaxDev).

## Запуск на RelaxDev
1. Создай **отдельный** репозиторий на GitHub (или GitVerse / GitFlic / GitLab) и положи в его корень файлы этой папки:
   `server.js`, `privacy.html`, `package.json`, `package-lock.json`, `README.md`.
2. Зайди на https://relaxdev.ru, зарегистрируйся (на баланс дадут 500 ₽ — это около 15 дней тарифа PRO).
3. Создай **новый** проект с именем **`dragla2`** (старый `dragla` не удаляй) и подключи репозиторий.
   Тип сборки — **Node.js** (платформа сама найдёт `package.json` и команды `build` и `start`).
   Ничего настраивать не нужно: сервер читает порт из переменной `PORT` и слушает `0.0.0.0:8080`.
4. Дождись окончания деплоя и открой `https://dragla2.relaxdev.ru` —
   должна появиться строка «Логово дракона: сервер работает».
5. Открой игру на двух телефонах → «По сети» → «Создать комнату» на одном и «Войти по коду» на другом.

Если имя `dragla2` окажется занято, создай проект с другим именем и замени адрес в игре:
в `game/dragon.html` найди `wss://dragla2.relaxdev.ru`, впиши свой и пересобери: `python3 tools/build.py all`.

## Политика конфиденциальности
Сервер показывает её по адресу **`https://dragla2.relaxdev.ru/privacy`** — эту ссылку можно указывать
в Google Play, ВКонтакте и Яндекс Играх. Текст лежит в `privacy.html`: перед публикацией впиши
в нём имя разработчика и адрес почты (места отмечены квадратными скобками).

## Как проверить без публикации
```
npm install
npm start                      # сервер на http://localhost:8080
```
Открой игру в двух вкладках с параметром `?server=ws://localhost:8080`, например
`http://localhost:8000/assets/www/index.html?server=ws://localhost:8080`.

## Полезно знать
- Комнаты и идущие партии хранятся в памяти сервера: при новом деплое или перезапуске они пропадают.
  Обновляй сервер, когда никто не играет.
- **Нужна ровно одна копия сервера (1 реплика)**: все игроки комнаты должны попасть на один и тот же сервер.
  Если в настройках проекта включено несколько реплик или автомасштабирование, игроки будут «теряться»:
  комната не находится по коду, лобби и партия подвисают. Проверь это в настройках проекта на RelaxDev.
  Как проверить: открой `https://dragla2.relaxdev.ru` и обнови страницу 5–10 раз. В строке есть «Копия сервера: …» —
  если это слово-метка всегда одинаковое, копия одна; если меняется — копий несколько.
- Если игрок потерял связь, у него есть 30 секунд, чтобы вернуться; потом его героем играет компьютер.
- Хозяин комнаты выбирает правила («Свободное исследование» или «Пробуждение дракона») и таймер хода (без таймера, 30 или 60 секунд).
  Время хода считают сами телефоны: когда оно вышло, этот ход за героя доигрывает компьютер.
- В одну комнату пускаются только телефоны с одинаковой версией правил. Если версия игры у игроков разная
  (например, ВК уже обновился, а Яндекс ещё нет), второй игрок увидит «У вас с хозяином комнаты разные версии игры».
  Поэтому обнови сервер одновременно с выпуском новой версии игры на площадках.
- Игра сама переподключается при обрыве связи, досылает потерянные ходы и догоняет партию, если пропустила её старт.
  Если сервер перезапустился, игроки увидят «Партия прервана» и смогут создать новую комнату.

## Настройки (переменные окружения)
| Переменная | По умолчанию | Что значит |
|---|---|---|
| `PORT` | 8080 | порт (RelaxDev задаёт сам) |
| `GRACE_MS` | 30000 | сколько ждать переподключения игрока в партии, потом за него играет ИИ |
| `LOBBY_GRACE_MS` | 15000 | сколько ждать игрока, пропавшего из лобби |

## Что нового во второй версии
- Сообщение `list` → ответ `rooms`: открытые комнаты той же версии игры, где партия ещё не началась,
  есть свободное место и хозяин на связи (до 30 комнат), плюс число игроков онлайн.
- Сообщение `open` (только хозяин): комната открытая — видна в списке, или закрытая — вход только по коду.
  Новые комнаты по умолчанию открытые.
- Всё остальное — как в первой версии, протокол совместим.
