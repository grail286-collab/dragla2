# Сервер dragla2: новые режимы «Охота на монстров» и «Спуск»

Клиент 3D отправляет в лобби `{t:'rules', v:'trophy'}` и `{t:'rules', v:'descent'}`.
Если в server.js есть список разрешённых правил, добавьте в него два значения:

```js
// было (пример):
const RULES = ['free', 'wake', 'hunt'];
// стало:
const RULES = ['free', 'wake', 'hunt', 'trophy', 'descent'];
```

Если проверка написана прямо в обработчике — то же самое:

```js
case 'rules': if (isHost && !room.game && ['free','wake','hunt','trophy','descent'].includes(m.v)) { room.rules = m.v; broadcastRoom(room); } return;
```

Больше ничего менять не нужно: `rules` уже уходит в сообщении `start` и в `roomView`.
Перезапустите сервер после правки.

Важно: в одной комнате должны играть только 3D-клиенты. Обычная 2D-версия
не знает «Спуска» и «Охоты на монстров» и разойдётся с остальными.
